# 🚀 EventHub

EventHub est une application Full-Stack de gestion d’événements avec authentification sécurisée JWT et une interface admin moderne.

---

# 📌 Description

EventHub permet aux utilisateurs de :

- créer et gérer des événements
- consulter les événements disponibles
- accéder à une interface admin sécurisée

Le projet est construit avec une architecture moderne, scalable et orientée SaaS.

---

# 🛠️ Stack Technique

## Frontend

- Angular 21
- Angular Material
- Standalone Components
- Feature-Based Architecture
- JWT Authentication
- HTTP Interceptor
- Route Guards

## Backend

- Spring Boot
- Spring Security
- JWT Authentication
- REST API
- Global Exception Handling

## Base de données

- PostgreSQL

---

# 🔐 Authentification

- Inscription utilisateur
- Connexion sécurisée avec JWT
- Intercepteur HTTP pour ajouter automatiquement le token
- Protection des routes avec guards Angular
- Sécurisation backend avec Spring Security
